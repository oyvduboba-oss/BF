# Brighty & Fox Learning

Статическая landing page для премиальных развивающих материалов Brighty & Fox.

## О проекте

Проект представляет собой демонстрационную страницу с:
- Каталогом обучающих карточек и комплектов
- Выдвижной корзиной
- Пошаговой инструкцией по печати и использованию
- Личным кабинетом с загрузками и историей заказов
- Модальными окнами для авторизации и preview-контента

## Структура репозитория

- `index.html` — основной HTML-файл сайта
- `css/styles.css` — стили оформления
- `js/app.js` — логика корзины, табов, модальных окон
- `README.md` — описание проекта
- `LICENSE` — лицензия проекта
- `.gitignore` — файлы и папки, которые не должны попадать в репозиторий

## Как запустить

1. Откройте `index.html` в браузере.
2. Для локального сервера используйте любой простой HTTP-сервер, например:
   ```bash
   python3 -m http.server 8000
   ```
3. Перейдите в браузере на `http://localhost:8000`.

## Использование

- Нажмите на карточку, чтобы открыть preview.
- Нажмите кнопку «В корзину», чтобы добавить товар.
- Откройте личный кабинет через «Войти».
